# 迁移验收记录

分支：`codex/migrate-vercel-markdown-resend`。迁移前基线：`f1f1cb4`（含原工作区未提交改动）。

当前架构：Next.js / Markdown / Vercel / Supabase / Resend / Jev。旧 Go、SMTP、数据库文章写入和容器发布入口已移除，Win98 界面保留。

本地验证覆盖（Bun 1.4.4 下 19 项测试、540 项断言，10 项桌面/移动端浏览器测试，以及独立数据库与故障隔离检查）：

- 408 篇原始故事逐字段和正文无损对照，稳定 ID、日期和来源保留；原 JSON 仅作测试快照。
- Node.js 24.22.1 生产构建与浏览器运行，无需 Go 或构建时数据库凭据，全部故事详情与归档生成。
- 开发、构建和本地启动检查实际 Node 大版本；Node 22 明确拒绝，Node 24 正常运行。Vercel 与 CI 输出实际运行版本。
- TypeScript 与 Biome。
- Supabase 连接失败时，首页、文章、归档、公开列表及站点地图仍可用，互动接口与 readyz 明确报告降级。
- Bun 业务及 SDK 集成测试：日期、时区、闰日、随机未读、已读 Cookie、校验、密钥加密、AI 脱敏、Resend 429、固定幂等键及载荷、不确定发送暂停。
- 独立 PostgreSQL：事务回滚、重复提交、订阅令牌、重发、退订取消、并发配置更新、权限、队列租约、webhook 重放/乱序、隐私清理。
- 本地真实 Supabase Auth/PostgREST + Chromium：桌面和移动端登录、反馈提交、确认、管理员处理、内部备注隔离、通知入队、退订、配置冲突、关闭公开注册、私有表拒绝匿名读取。
- 官方 AI SDK 7.0.154 请求 Gateway 的 Jev Boolean 合约、概率 0 / 0.2 / 0.5 / 0.8 / 1、拒答及非法响应、429 / 503 不自动重试、超时取消、缺失凭据和预算耗尽时保留反馈、密钥 / 模型 / 阈值热更新。
- 旧 Cloudflare 设置只读兼容、不变更 revision；首次 CAS 保存迁移且不泄露旧 token，新密钥及审计不回显密文或明文。后台桌面 / 移动端保存、刷新、密钥不回显及非法阈值拒绝。
- 已有反馈应用数据库增量迁移后保留历史置信度，新概率为空；新概率单独入库，幂等重复不覆盖，越界概率被数据库拒绝，RPC 权限保持。`/readyz` 验证新列存在。
- 浏览器公共阅读、筛选、窗口键盘操作、隐私页不加载追踪、无效文章 404 与完整站点地图。

明确的接口调整：管理员使用邮箱登录；邮件配置从 SMTP 改为 Resend；旧文章写入接口返回 410；AI 设置改为 Jev / AI Gateway，垃圾概率与历史置信度独立；不确定或超出幂等窗口的邮件必须人工核查后处置。

部署后的外部验收尚需生产/预览项目配置：真实 Resend 域名及收件箱、Vercel Preview、自定义域名与云端 Cron，以及真实 Jev 调用和中文标注样本的阈值校准。仓库内的网络模拟验证不代表真实邮件已经送达或真实模型已达到某个准确率。本轮没有发送真实邮件、调用计费模型或切换正式域名。
